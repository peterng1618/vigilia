What this cut settles

The Add pane, and why the rail is three

  • Cards, Shapes, Charts, Text — exactly insertGroups(), which is already the one owner both the pane and the old Insert menu rendered. 8 units, 8 shapes, 4 charts.
  • Place a file sits at the foot, disabled for anything that is not png or svg — which is isPlaceable's rule, and vg-154's insert half arriving in the pane.
  • Cards get diagrams; layer rows do not. The card set is a fixed library of eight, so a marked tile is honest. A card on the canvas is an arbitrary group, so its layer row stays a generic glyph.
  • The rail is Composition · Add · Tokens, plus the gear. Document left the rail because its contents are document-level, which is your header rule.

Document, and one thing still open

  • The Document menu carries Artboard, Background, Metadata, References, Rename theme, Save package — the four scopes vg-153 measured in one scroll, split by whether they are a command or a library.
  • References is read-only and says so, in the menu, before you open it.
  • Still open: do Artboard and Metadata open dialogs, or is there a fourth rail slot after all? A menu of dialogs is what your rule implies; a pane is what the old editor did.
  • Still open: the shell palette now only exists inside Settings, so there is no at-a-glance readout of which palette you are in. That is the cost of moving the chip.
