What this cut settles

The Add pane, and the four-slot rail

  • Cards, Shapes, Charts, Text — exactly insertGroups(), which is already the one owner both the pane and the old Insert menu rendered. 8 units, 8 shapes, 4 charts.
  • Import a file sits at the foot. Images and SVGs can be placed; fonts, videos and unplaced files remain in the declared-asset list. Preview, byte replacement and reference-safe removal stay reachable below this illustrative insert grid.
  • Cards get diagrams; layer rows do not. The card set is a fixed library of eight, so a marked tile is honest. A card on the canvas is an arbitrary group, so its layer row stays a generic glyph.
  • The rail is Composition · Add · Tokens · Document, plus the gear. The gear opens Settings, not a fifth pane.

The reviewed contract

  • Document holds Artboard, Background, Metadata and References. File keeps save/release commands. No Document menu repeats the pane.
  • References says read-only before opening. The empty selection column carries only its subject and guidance.
  • Compact view chips are illustrative, not exhaustive. The complete lens list and zoom commands stay reachable; resolve crowding without automatically replacing this cluster with a large chooser.
  • Palette swatches stay. Settings loses the header's at-a-glance palette readout, not its visual palette previews. Required contrast and keyboard behaviour are measured in the product.
