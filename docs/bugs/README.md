# Bugs

Non-critical bugs unresolved after three repair attempts live in `open/`. Each
file holds current evidence and next pickup action. Resume only when a user
asks. Move resolved bugs to `closed/`; closed bugs need no index entry. Do not
duplicate bug details in status, specs, reports or other docs; plans may link
relevant bugs.
